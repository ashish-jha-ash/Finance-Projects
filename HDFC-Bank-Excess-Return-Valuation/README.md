# HDFC Bank Excess Return Valuation

## Overview
This project estimates the intrinsic value of HDFC Bank using the Excess Return (Residual Income) valuation model, which is widely used for valuing banking and financial institutions.

## Objective
- Estimate intrinsic equity value
- Compare intrinsic value with market price
- Analyze valuation sensitivity under different assumptions

## Tools Used
- Microsoft Excel

## Methodology
- Forecast Book Value Per Share
- Forecast Return on Equity (ROE)
- Estimate Cost of Equity
- Calculate Excess Returns
- Discount Excess Returns to Present Value
- Determine Intrinsic Value

## Key Features
- Dynamic assumption sheet
- Financial statement projections
- Sensitivity analysis
- Investment recommendation
